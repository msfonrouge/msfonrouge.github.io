Product

Tallyfork

Liverecipe costing for restaurants and caterers, built and run by me.

Problem

Kitchens set prices without knowing what a dish really costs. The cost changes every time a supplier changes a price.

What I built

  • Ingredients with suppliers, pack sizes, yield and price history.
  • Recipes inside recipes, scaling, cost per portion and food cost percentage.
  • Menus with a price per guest and a suggested price.
  • Import from a spreadsheet, and a clear reason when a recipe has no cost yet.

Result

A working product, now open by invitation.
