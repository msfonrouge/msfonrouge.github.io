Small first steps in a catering business

My first work for a catering and events business was small. Quotes lived in their management system, but the steps around them were done by hand.

I added two things. When a quote had an event date, the system now created the event in the shared calendar by itself. And a new button sent the quote to a script that turned it into a proposal document.

I also wrote a script that read sales per product from the system the cash registers use, so the numbers could be used outside it.

None of this is impressive on its own. But it is a first step: once the data flows by itself, you can start to trust it, and then build on it.
