A website, and the parts nobody sees

In 2020 I developed a website for a strategy consulting firm. The design was not mine: a friend, a designer, made it. I did the development, in WordPress.

The pages were the easy part. The work nobody sees took more care: moving the site to a new hosting account, getting the contact form to actually deliver email, and updating the server so the site kept running.

The site is live now.

It taught me something I want to keep: a project is not done when it looks right. It is done when the boring parts work and the client can forget about them.
